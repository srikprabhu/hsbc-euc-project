# VBA to Python Modernizer UI

A responsive React front end recreated from the supplied dashboard reference. The central workspace uses three exclusive tabs:

1. Business Rules
2. Generated Python Code
3. Reports & Outputs

## Run locally

```bash
npm install
npm run dev
```

Open the URL printed by Vite.

## Production build

```bash
npm run build
npm run preview
```

## Included interactions

- Excel file picker and drag-and-drop area
- Simulated migration status change
- Three central output tabs
- Business rule JSON download
- Python code copy and download
- Report download controls
- Responsive desktop, tablet, and mobile layout
